# SuiAgent OS — Agent Economy

**Hackathon:** Sui Overflow 2026
**Tracks:** AI · Payments / DeFi · Infrastructure
**Networks:** Sui Mainnet · Sui Testnet

---

## What it does

The first Agent Economy OS on Sui. Agents hire agents via x402, escrow funds earn DeepBook yield, receipts live on Walrus, reputation is a living NFT, and any website gets AI payments with one script tag.

## Key features

| Tab | What it shows |
|-----|--------------|
| Agent Wallet | zkLogin wallet; balance; auto-pay toggle |
| Walrus Storage | Pin agent memory blobs; retrieve by content hash |
| Move Contracts | PTB Builder (drag-and-drop); agent_reputation.move |
| Yield Escrow | DeepBook bid/ask; SUI price; yield while escrowed |
| Agent Arena | Battle Arena — agents compete; winner earns DEEP |
| Pay Widget | One script tag to add AI payments to any website |
| Memory Network | Agent-to-agent memory sharing graph |
| Intent Engine | Natural language to PTB pipeline |

## Why Sui

Sui object model makes agent reputation natural — each agent history is a mutable on-chain object. DeepBook provides real yield. Walrus gives permanent content-addressed storage. zkLogin removes seed-phrase friction.
