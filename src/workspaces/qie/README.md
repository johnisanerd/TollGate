# QIE Agent Payment Gateway

**Hackathon:** QIE Hackathon 2026
**Track:** DeFi Payments · AI + Web3 · Gaming · Creator Hub
**Networks:** QIE Mainnet (chainId 1983) · QIE Testnet

---

## What it does

Merchants list paid AI and API services. Agents settle through the QIE payment rail. QIE Pass NFTs gate premium features. An on-chain oracle provides price data. Agents build a credit score via QieAgentCredit.sol.

## Key features

| Tab | What it shows |
|-----|--------------|
| Merchant Checkout | List and manage paid services; pricing tiers |
| QIE Wallet | Agent wallet balance; spend history |
| QIE Pass | NFT-gated access; mint / verify Pass |
| Oracle Feed | Live price oracle; subscribe per query |
| Agent Credit | On-chain credit score; history |
| Game Store | Gaming asset marketplace |
| Creator Hub | Creator monetisation via QIE rail |

## Deployed contracts (QIE Testnet — chainId 1983)

QieCheckout, QiePass, QieAgentCredit, QieOracleFeed — deploy via `npm run deploy:qie`
