# Polygon Agent Commerce

**Hackathon:** Polygon Hackathon
**Track:** SME Merchant Payments · Cross-Border Commerce · Agent Infrastructure
**Networks:** Polygon zkEVM (`0x44d`) · Polygon Cardona Testnet (`0x985`)

---

## What it does

SME merchants publish paid APIs in 30 seconds. Agents and buyers settle per call in USDC on Polygon zkEVM — UAE commerce infrastructure for AI-powered trade.

## Key features

| Tab | What it shows |
|-----|--------------|
| Merchant Mode | Publish an API as a paid service; manage pricing |
| Trade Finance | Cross-border invoice settlement; USDC escrow |
| Agent Marketplace | Browse services; pay per call with agent wallet |
| USDC Payments | Batch transfers; live transaction feed |
| Receipts | Full receipt history with explorer links |

## Why Polygon

Polygon zkEVM offers EVM-equivalent execution with sub-cent USDC transfer costs. The UAE-focus aligns with Polygon MENA expansion and cross-border USDC settlement corridors.
